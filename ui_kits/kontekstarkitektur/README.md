# UI-kit: kontekstarkitektur.no

Blå flate (`.tema-blaa`, `#AEEBFB`) — den tredje nettstaden i universet. Rekonstruert frå
`Kontekstarkitektur i dag - blaa.dc.html` i kjelderepoet (aregh/designsystem).

**Skjermar** (klikk i menyen): Heim, Metoden, Kurs. Blogg og Om meg finst ikkje i
kjeldematerialet og er med vilje tomme.

**Merk om flatetemaet:** på blå flate er sirkel-badgen gul (`--badge-flate: #FFE484`), fordi
blå badge på blå flate er usynleg. Heim-sida brukar ein kvit statistikk-sirkel, slik som i
kjelda — kvit er nøytral flate, ikkje ein brandfarge.

Filer: `index.html` (montering), `Skjermar.jsx` (Heim, Metoden, Kurs, Botn).

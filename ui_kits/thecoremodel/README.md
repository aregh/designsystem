# UI-kit: Thecoremodel.com

Recreation av bok-sida på **thecoremodel.com** (engelsk univers).

- **Flate:** rosa #FEC4B2 (alternativ sideflate frå brandet)
- **Språk:** engelsk
- **Struktur:** SiteHeader (engelsk meny) → hero (stor tittel + roterande bokomslag) →
  tosplitta innhald med to store sitat i høgrekolonnen → CC-lisens fineprint → «Get in touch»

Same designsystem, berre annan sideflate og språk — viser korleis brandet skalerer på tvers av
dei to nettstadene. Komponert av SiteHeader, Button, Quote og TextLink via `_ds_bundle.js`.
